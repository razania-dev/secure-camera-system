# secure-camera-system
Unityで作成したカメラ追従システム

マウス位置をターゲットとして追従する監視カメラシステムです。
複数のアーム構造を用いて、現実的な回転制御を実装しています。

技術要素

- Quaternionを用いた回転分解（Yaw / Pitch）
- ローカル座標への変換による親子関係の考慮
- 回転制限（Clamp）による可動域の制御
- Slerpによる滑らかな回転補間

---

操作方法

- マウス位置にカメラが追従します

---

工夫した点

- 回転を「水平（Yaw）」と「垂直（Pitch）」に分離することで、各関節の自然な動きを実現 
- 親オブジェクトの影響を考慮したローカル回転制御
- 再利用可能な設計（AngleCalculation / RotationController）
